## Motivation

When i started a new year at Ain shams medicine, i found it difficult and incovenience to keep collecting materials for a long time and I wished if there was a ready list that I can use to start right away. Here comes this website, an all-in-one place where we can share our medicine materials with each other and use it to start studying immedietly.



## 🧞 Commands

All commands are run from the root of the project, from a terminal:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `pnpm install`             | Installs dependencies                            |
| `pnpm dev`             | Starts local dev server at `localhost:4321`      |
| `pnpm build`           | Build your production site to `./dist/`          |
| `pnpm preview`         | Preview your build locally, before deploying     |
| `pnpm astro ...`       | Run CLI commands like `astro add`, `astro check` |
| `pnpm astro -- --help` | Get help using the Astro CLI                     |
